# TogetherTV

Синхронный просмотр видео между зрителями.

## Запуск

`npm install`

`npm run dev`

## Realtime

Сейчас API использует память экземпляра Vercel. Для настоящей синхронизации между разными serverless-инстансами подключим Upstash Redis и заменим хранилище в `app/api/state/route.ts`.

## YummyAnime

Поле X-Application находится в админке и не отправляет ключ в этот проект. Интеграцию API подключаем отдельным серверным маршрутом после подтверждения формата ответов API.
